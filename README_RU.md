# Профессиональный профиль для GitHub Pages

Готовый статический сайт без сборки. Фотография и все логотипы хранятся локально в папке `assets`.

## Публикация через интерфейс GitHub

1. Создайте репозиторий с нейтральным случайным названием. Не добавляйте описание, имя или должность владельца профиля.
2. По возможности используйте **приватный репозиторий**. GitHub Pages из приватных репозиториев доступен для GitHub Pro, Team и Enterprise. Сам опубликованный сайт при этом обычно остаётся публичным; закрыть доступ к Pages можно только в поддерживаемых корпоративных конфигурациях.
3. Загрузите в корень репозитория содержимое этой папки. `index.html` должен лежать в корне. Не загружайте исходные DOCX, PDF или ZIP-архив.
4. Откройте `Settings` → `Pages`.
5. В `Build and deployment` выберите `Deploy from a branch`, затем ветку `main` и каталог `/(root)`. Нажмите `Save`.
6. Подождите несколько минут. Адрес появится в этом же разделе.

## Защита от обнаружения

- Личные данные и текст резюме хранятся в `data.js` в кодированном виде, поэтому обычный поиск GitHub по имени, email или фразам из резюме не должен находить их в исходниках репозитория.
- На странице установлены `noindex`, `nofollow`, `noarchive`, `nosnippet` и `noimageindex`.
- `robots.txt` запрещает обход сайта.
- Не используются sitemap, Open Graph, структурированные данные, аналитика или внешняя загрузка изображений.
- Файл `.gitignore` предотвращает случайный коммит исходных резюме, PDF, архивов и временных файлов при работе через Git.

`.gitignore` не скрывает уже опубликованные файлы и не управляет поиском GitHub. Поэтому важны нейтральное название репозитория, отсутствие описания, приватный репозиторий при доступном тарифе и кодированное хранение персонального текста.

Важно: эти меры уменьшают обнаруживаемость, но не создают настоящую секретность. Любой человек с прямой ссылкой может открыть страницу, посмотреть исходный код, декодировать данные и переслать ссылку.

## Проверка перед рассылкой

После публикации откройте страницу на компьютере и телефоне, переключите `English` / `Русский` и проверьте ссылки на email и телефон.

## Обновление

Внешний вид находится в `styles.css`, поведение — в `script.js`, фотография — в `assets/profile.jpg`. Персональные данные в `data.js` создаются из исходных резюме; не редактируйте кодированную строку вручную.
